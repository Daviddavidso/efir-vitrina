# Витрина финпредложений + телеграм-бот для правок

Нейтральная: без привязки к каналу или бренду. Название сайта, подзаголовок и кнопка Телеграма меняются в боте (⚙️ Настройки).

Сайт: `index.html` + `css/` + `js/` + `data.json` (каталог). Бот: `bot/`.
Каталог правится в Telegram — сайт перечитывает `data.php` при каждом открытии.

## Что умеет бот

- Разделы → офферы → карточка оффера. Правится всё: название, компания, главная строка,
  описание, детали (по строке), ссылка, крео (картинкой), логотип, плашки, раздел, порядок,
  показать/скрыть, удалить.
- Новый оффер создаётся скрытым — заполнил поля, нажал «✅ Показать».
- Плашки: включаются кнопками в карточке; список плашек и их цвета — «🏷 Плашки».
- Разделы сайта: название, текст кнопки, порядок, тип (вакансии рисуются своим видом), новые разделы.
- Настройки сайта: название, подзаголовок, телеграм, строка в подвале.
- «↩️ Откатить» — отменяет последнее изменение, можно несколько раз подряд (хранится 40 шагов).
- Поиск: просто напиши боту часть названия оффера.
- Админы: вход по коду из конфига, остальные — по одноразовой ссылке (живёт 30 минут).

## Запуск на хостинге (PHP 7.4+, HTTPS обязателен)

1. Залей все файлы, кроме `tools/`, в корень сайта.
2. Создай бота в @BotFather → получи токен.
3. `bot/config.sample.php` → скопируй в `bot/config.php`, заполни: `token`, `bot_username`,
   `site_url` (https://…), `secret` (20–40 латинских букв/цифр), `bind_code`.
4. Открой `https://сайт/bot/install.php?key=СЕКРЕТ` — пропишется вебхук, покажет, всё ли с правами.
5. Напиши боту `/start КОД_ИЗ_bind_code` — ты админ.

Права: PHP должен писать в `data.json`, `uploads/` и в закрытую папку `.efir-private`
(создаётся над корнем сайта; если нельзя — укажи `private_dir` в конфиге).

## Проверка без Telegram

`php tools/bot-test.php` — 36 проверок: доступ, навигация, правка полей, крео, плашки, откат,
разделы, приглашения.

## Лендинг агентства

Ленд «Смена» (`~/smena-rekrut`) может брать вакансии отсюда: в его `js/config.js`
укажи `source: 'https://этот-сайт/data.php?cat=hr'` — вакансии будут правиться в этом же боте.

## Цифры

Все условия в стартовом каталоге — пример. Ставки, выплаты и кэшбэк вписывать только
подтверждённые партнёркой. Ссылки пустые — кнопка «Оформить» показывает «ссылку скоро добавим».
